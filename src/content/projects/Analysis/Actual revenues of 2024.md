  - "1. Context: Extension of a previous dashboard; the sales team asked for more detail after the first review."
  - "2. Problem: Revenue data was split across 12 separate Excel files, so pulling one clear number used to take over an hour of switching between files. Every new question meant redoing that hour."
  - "3. Approach: I consolidated and cleaned data from all 12 sources with Excel and Python into one dataset, then delivered a Power BI dashboard breaking revenue down by category across all 4 quarters. I could have kept merging the files by hand each time someone asked, but that repeats the same hour of work every month, so I built one dataset the dashboard reads from instead."
  - "4. Result: What took over an hour now takes under a minute; a yearly report giving a clear, immediate view of revenue performance all year."
  - "5. Lesson: The real deliverable wasn't the dashboard itself. It was making the underlying data reusable, so the next question doesn't cost another hour."
