Approach: I consolidated and cleaned data from all 12 sources with Excel and Python into one dataset, then delivered a Power BI dashboard breaking revenue down by category across all 4 quarters. I could have kept merging the files by hand each time someone asked, but that repeats the same hour of work every month, so I built one dataset the dashboard reads from instead."

  - "5. Lesson: The real deliverable wasn't the dashboard itself. It was making the underlying data reusable, so the next question doesn't cost another hour."
